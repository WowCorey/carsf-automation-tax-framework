# CARSF V1.5 Source-Locator Verification Pack

This is a source-locator verification pack only. No new data is loaded by this build. This does not externally verify source values, does not scrape public sources, and does not call external APIs. Ready for manual review does not mean reviewed and does not mean externally verified.

This is not calibration. Calibration has not been completed. Public data does not prove the model works. Realistic placeholders remain placeholders. Realistic placeholders are not real data and are not calibrated. Source references are not loaded datasets. Restricted-data requirements are not data access.

This is not legal advice, not tax advice, not ATO guidance, not Treasury modelling, not PBO costing, not economic validation, not welfare validation, not statistical validation, not operational readiness, not legal sufficiency, and not official status. It does not determine actual tax payable and does not modify firm-level CARSF liability.

## What It Adds

- Loaded public value cards for the five existing Build 27 loaded extracts.
- Source-reference-only cards for the three existing source-reference-only extracts.
- Placeholder-anchor cards for the eleven realistic placeholder anchors.
- Restricted-blocker and forbidden-repo-data cards from the Build 28 evidence map.
- Reviewer checklists for URL, locator, value, unit, period, geography, aggregate-only status, and non-claim boundaries.

## What Reviewers Inspect

Reviewers can inspect whether the source URL, exact locator text, value note, unit, period, and geography are enough for manual review. The Fair Work card also exposes the internal arithmetic check `24.95 * 38 = 948.10`.

## What Must Not Be Inferred

The pack is not source verified, not externally verified, not calibration, not validation, not approval, not ATO guidance, not Treasury modelling, not PBO costing, and not a tax-payable result. It only packages locator metadata and manual-review checklists.
