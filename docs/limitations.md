# Limitations

This is a concept model only.

It is not legal, tax, Treasury, or ATO advice. It is not draft legislation and it is not an official Commonwealth position.

All sector values are placeholders until calibrated with real data. Firm-level liability cannot be claimed as accurate without real schedules.

HILDA, ATO, ABS, DSS, HELP, superannuation, state payroll tax, and industry data are required before the framework can be treated as more than a concept prototype.

Legal review is required before external policy use, including review of constitutional power, retrospectivity, acquisition on just terms, state preference, treaty exposure, trade retaliation risk, privacy, and disclosure powers.

Tax incidence and behavioural elasticity remain unresolved. The model may be wrong if automation creates large productivity dividends that offset fiscal losses.

The framework must not be used to make claims about actual tax payable.
