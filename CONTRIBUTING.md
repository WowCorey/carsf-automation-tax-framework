# Contributing

This is currently a private research/prototype repository.

## Contribution Rules

- Do not add API keys, tokens, credentials, personal data, or confidential taxpayer information.
- Label all values as confirmed baseline figures, illustrative assumptions, placeholder values, or future research requirements.
- Do not present model outputs as actual Australian tax payable.
- Do not describe CARSF as final law or settled government policy.
- Keep policy wording, schedules, examples, and code aligned.
- Add or update tests when changing formula behaviour.

## Development

```powershell
python -m pip install -r requirements.txt
python -m pytest
```

Use focused commits. Keep generated cache folders out of version control.
