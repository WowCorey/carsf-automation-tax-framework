# Export Notes

The policy paper is maintained in Markdown so it can be versioned, reviewed, and exported later.

## Current Source Files

- `paper/CARSF_V1_4.md` is converted from the supplied PDF.

- Preserve status disclaimers.
- Preserve source notes.
- Keep equations readable.

Potential future export tooling: Pandoc or Quarto, with a Treasury-style PDF template if approved.
